# Домашнее задание к занятию «Репликация и масштабирование. Часть 2»

## Задание 1

### Active Master + Passive Slave

В данной схеме Master обрабатывает все операции записи, а Slave используется как резервный сервер.

Преимущества:

- отказоустойчивость;
- наличие резервной копии данных;
- возможность выполнять резервное копирование на Slave;
- простота настройки.

### Master + несколько Slave

В данной схеме один Master отвечает за запись данных, а несколько Slave используются для чтения.

Преимущества:

- распределение нагрузки на чтение;
- повышение производительности;
- масштабируемость системы;
- высокая доступность данных.

## Задание 2

Исходная база данных содержит таблицы:

- users;
- books;
- stores.

### Вертикальный шардинг

Разделение данных по разным базам:

| База данных | Таблицы |
|------------|----------|
| DB_USERS | users |
| DB_BOOKS | books |
| DB_STORES | stores |

Схема:

```text
            Приложение
                 |
    +------------+------------+
    |            |            |
 DB_USERS    DB_BOOKS    DB_STORES
    |            |            |
  users        books       stores
```

### Горизонтальный шардинг

Таблица пользователей разбивается по диапазонам идентификаторов.

| Сервер | Данные |
|---------|---------|
| USERS_01 | id 1–100000 |
| USERS_02 | id 100001–200000 |
| USERS_03 | id > 200000 |

Схема:

```text
            Приложение
                 |
      +----------+----------+
      |          |          |
   USERS_01   USERS_02   USERS_03
```

### Режимы работы серверов

| Сервер | Режим |
|----------|----------|
| Master | Read/Write |
| Slave 1 | Read Only |
| Slave 2 | Read Only |
| Slave 3 | Standby |

### Вывод

Вертикальный шардинг позволяет разделить данные по назначению, а горизонтальный — распределить нагрузку между серверами. Использование шардинга совместно с репликацией повышает производительность и отказоустойчивость системы.
